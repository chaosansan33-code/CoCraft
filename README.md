此版本不包含或覆蓋 `images/`。請把壓縮檔內所有檔案直接上傳到 GitHub repository 根目錄，遇到同名檔案請選擇覆蓋，並保留 GitHub 原有的 `images/` 資料夾。

## 本版流程

- 「加入共養」代表直接購買該件實體作品，費用同時包含作品上的 NFC 與專屬數位技藝履歷。
- 油紙傘結帳固定為 NT$10,000；竹編為 NT$333；春仔花為 NT$2,000。
- 原本的分級「共養方案」已退出導覽；舊的 `plans.html` 與 `plan-detail.html` 會自動導回商品頁，避免舊 GitHub 網址繼續顯示混淆內容。
- NFC 操作手冊改為四頁逐步操作，完成確認後才會開啟數位履歷。
- 數位履歷新增「近期師傅故事紀錄」。
- 結帳與聯絡表單送出後都有完成訊息及「返回主頁」。
- 全站保留繁體中文、英文、日文、閩南語、客語切換。

## 上傳方式

1. 解壓縮後，將所有 HTML 檔案上傳到 repository 根目錄並覆蓋舊檔。
2. 本包是自包含版本：排版與互動已嵌入每一個 HTML，不需要另外上傳 CSS 或 JS。
3. 不要刪除 GitHub 內原有的 `images/`，並確認圖片檔名英文大小寫完全一致。
