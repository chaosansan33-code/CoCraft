# 記藝共養所 V5｜HTML 單檔上傳版

## 上傳方式

1. 解壓縮本檔案。
2. 將全部 `.html` 檔案上傳到 GitHub repository 根目錄。
3. 覆蓋所有同名檔案並確認 commit。
4. 保留 GitHub 原有的 `images/` 資料夾。

本版每個 HTML 已內嵌完整 CSS、互動與五語翻譯，不依賴 GitHub 上的 `css/style.css` 或 `js/` 檔案，可避免舊樣式快取或漏傳檔案造成跑版。
